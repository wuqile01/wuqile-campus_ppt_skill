# 高校课程汇报 / 答辩 PPT Skill · 设计思路 v0.2

> 参考：`guizang-ppt-skill`（归藏，HTML 网页 PPT）与 OpenAI `presentations` skill（原生 pptx + 模板跟随 + 渲染质检）。
> v0.2 的变化：用你上传的两个西南财经大学模板做了**实测拆解**（结构 / 颜色 / 字体 / 页型 / 体积），并用本机工具链验证了"克隆样张生成"的可行性。设计从"构想"变成"有实证依据的方案"。

---

## 摘要（一页看懂）

**做什么**：输入 `学校模板.pptx + 论文/报告.docx + 场景信息`，输出 `答辩.pptx + 质检报告`；讲稿 / 答辩Q&A预案 / 备份页**按需**（运行开始时问用户，不默认生成）。

**怎么做到"像学校自己做的"**：不是重新设计风格，而是**克隆模板里已有的样张页**（保留标题栏、校徽、配色、字体、装饰图），只替换文字和图表——实测证明这是唯一能保住模板视觉的路径。

**怎么做到"能直接上台讲"**：把长文压缩成"一页一论点"的论证链，每页一个结论句标题 + 一个证据单元；同时强制投影可读性（字号下限、信息预算），**不复制模板样张那种 12pt / 单页 300 字的信息密度**。

**三条不可越过的线**：学术诚信（不生成实验数据图）、模板保真（不自创配色字体）、交付质量（体积 <15MB、字体不缺失、无溢出）。

## 1. 定位与边界

**合适（仅限学术汇报）**：日常课程汇报、小组作业展示、文献/组会汇报、开题答辩、中期检查、毕业答辩（本/硕/博）。

**不做**：大创/竞赛路演/商业计划书（页数多、营销属性强），以及一切页数超过 25–40 页的大制作。

**不合适**：数据大屏、多人协作编辑、纯美化单张图、要求编造数据/结论、无 PPT 的纯口头答辩。

**目标用户**：以西财这类**财经/经管文科学生**为主（由上传模板推断，待确认），可扩展到全学科。

## 2. 实测：两个西南财经大学模板拆解

### 2.1 基本信息

| 维度 | 【典雅红】 | 【西财蓝1】 |
|---|---|---|
| 画布 | 16:9，13.33 × 7.5 in | 同 |
| 文件体积 | **243 MB** | **104 MB** |
| 页数 | 17 页样张 | 13 页样张 |
| 版式 | 24 个（2 套母版，重复） | 10 个（3 套母版，重复） |
| 主题色 | 仍是 Office 默认蓝（4874CB） | 深蓝 00144C |
| **实际用色** | **红 B1221C（186 处）、金 D08349、米 F6EDCE、深红 A00303** | **蓝 376FFF、灰蓝 637490、深蓝 1271BA** |
| 字体 | **思源宋体 CN Heavy/Medium**（衬线） | 微软雅黑（无衬线） |
| 字号 | 12–60pt，正文低至 **12pt** | 12–287pt（大数字装饰） |
| 单页最高字数 | **305 字** | **342 字** |
| 动画/切换 | 无 | 无 |
| 备注 | 7 页空白备注 | 5 页空白备注 |

> 实测渲染图见 `模板实测/`（封面、目录、章节页、图文页、结尾页）。

### 2.2 七个关键发现（直接改变设计）

**① 装饰在"页面"上，不在"版式"里。**
两套模板的 slideLayout 基本是空壳（典雅红 12 个版式只有占位符，母版也只有 5 个占位符）。实测 `add_slide(layout)` 生成的是**纯白页**。真正的页面设计（背景照片、色块、圆角卡片、标题栏）全部画在**幻灯片**上。
→ **结论：不能"套版式"，只能"克隆样张"。** 这是整个生成架构的地基。

**② 主题色 ≠ 品牌色。**
典雅红的 theme 里 accent1 还是 Office 默认蓝，真正的红色 `B1221C` 硬编码在 186 个形状里；西财蓝 theme 是 `00144C`，实际大面积用 `376FFF`。
→ **结论：模板画像必须统计"实际用色"（扫描 srgbClr/schemeClr 频次），不能只读 theme.xml。**

**③ 样张就是版式库。**
17/13 页样张覆盖了：封面、目录（章节列表）、章节过渡（大数字+背景图）、图文排版、多列卡片、纯文字多段、结尾致谢。每页 6–26 个形状、2–8 张图、0 个正文占位符。
→ **结论：给每个样张登记"骨架"（文本框 name/坐标/字号/run 结构/容量字数），生成时按角色选样张再填。**

**④ 视觉语言 ≠ 信息密度（最容易被忽略）。**
样张是"排版示意"，正文 12pt、单页 300+ 字。这在投影答辩时**完全不可读**。
→ **结论：保留样张的视觉语言（标题区、logo、配色、装饰），但重设信息预算：正文 ≥18pt、单页 ≤6 行 / ≤80 字；超出就拆页或改图，绝不缩字号。**

**⑤ 文件体积失控。**
单张图片最大 **42MB**，30 张图共 231MB。学生要微信传、U 盘拷、教务系统上传，243MB 的 pptx 是灾难。
→ **结论：交付前必须做媒体治理——降采样到 ≤1920px、JPEG q80、无用媒体/母版/版式清理，目标 <15MB。**

**⑥ 字体是隐形地雷。**
模板用了 思源宋体 CN、微软雅黑、阿里巴巴普惠体、MiSans、Poppins。本机渲染时全部缺失，**静默回退到 PingFang SC（无衬线）**——衬线模板在质检图里变成黑体，学生电脑上又是另一种样子。
→ **结论：字体归一化 + 替换表 + 显式告知；`run.font.name` 只写 `a:latin` 不够，必须同时写 `a:ea`/`a:cs`。**

**⑦ 母版/版式大量重复。**
典雅红 2 套母版 12+12 版式，西财蓝 3 套母版几乎完全重复。
→ **结论：清理未使用母版/版式，减少文件体积与"模板污染"风险。**

### 2.3 实测验证的工具链（已跑通）

| 能力 | 结论 |
|---|---|
| 解析模板（母版/版式/占位符/主题/媒体） | ✅ python-pptx 1.0.2 + 手写 XML |
| **克隆样张并保留照片/logo/装饰** | ✅ `deepcopy` spTree + `p:bg` + `relate_to` 重映射 rel（实测封面/图文页克隆完整） |
| 替换文本不破坏样式 | ✅ 保留首个 run 的 rPr、合并全文、删除其余 run（按 run 逐个替换会重叠乱码） |
| 写演讲备注 | ✅ `slide.notes_slide`（克隆不继承 notes，需单独写） |
| 原生图表/表格 | ✅ `add_chart`/`add_table`（克隆含图表页需重建 chart part，否则共享） |
| 渲染质检 | ✅ LOKit CLI，`--pages` 只渲染改动页，返回 `missingFonts` |
| 中文字体 | ⚠️ 缺失字体静默回退；需 `--font-fallbacks` 显式映射 |
| SmartArt / OMML 公式 | ❌ 无 API（两模板均为 0 个，风险可控） |
| 自动缩排（autofit） | ⚠️ python-pptx 不计算，需自己按字数预算降字号或拆页 |

## 3. 六个关键判断

1. **交付物必须是原生 `.pptx`**：要交老师、上传系统、在答辩教室 Windows+Office 放映，只有原生格式能复用学校模板。
2. **风格必须"服从"而非"创造"**：模板承载学校身份与格式要求，skill 只负责读懂、稳住、补齐。
3. **生成方式 = 克隆样张**（实证结论）：版式是空壳，装饰在页面上；三条路径见第 6 节。
4. **内容是"论证链"不是"叙事弧"**：评委只关心"解决什么问题 → 别人差在哪 → 你怎么做 → 凭什么信你"。
5. **学术诚信红线**：不生成实验数据图、不编造结论、AI 只做示意图并标注（依据见 7.5）。
6. **体积与字体是交付质量的一部分**：243MB / 缺字体 = 不可用，必须在质量门禁里。

## 5. 总体架构

```
输入：场景 / 文字稿 / 个人信息 / 数据图表
          │
          ▼
   内容引擎：文稿抽取 → 论证链 → 逐页文案稿 copy.md
          │                    ▲
          │              【确认门 1】用户逐页确认文案（此时不看模板）
          ▼
   模板引擎：模板画像 → 从文案反推版式 → visual-plan.md
          │                    ▲
          │              【确认门 2】用户确认视觉方案
          ▼
   单页样张（信息密度最高的那页）→ 渲染 → 用户确认
          │                    ▲
          │              【确认门 3】确认后成为 golden page（视觉基准）
          ▼
   批量生成：克隆样张 + 结构化替换 + 写备注 + 图表/表格合成
          ▼
   质量门禁：结构校验 → 渲染目检 → 硬规则 → 体积/字体治理
          ▼
   交付：pptx / 质检报告.md（讲稿、Q&A、备份页按需）
```

**四份中间产物 + 三道确认门**（顺序不可颠倒）：

| # | 中间产物 | 内容 | 确认门 / 作用 |
|---|---|---|---|
| 1 | `copy.md` | **逐页文字内容**：标题（结论句）/ 正文条目 / 证据 / 备注 / 时长 | **门 1**：内容先对齐，避免"为套模板把不同板块塞一页" |
| 2 | `template-profile.json/.md` | 母版/版式/实际用色/字体/样张骨架/角色标签/缺口/污染 | 模板保真的事实底稿 |
| 3 | `visual-plan.md` | 每页用哪个样张或合成路径 + 字号密度基准 + 配色 | **门 2**：版式服从内容，不是内容迁就版式 |
| 4 | `build-plan.json` | 机器可读：每页样张、字段、图表、备注 | 可复现、可增量修改 |
| — | `visual-baseline.md` | 样张确认后的字号/密度/边距/句式基准 | **门 3**：批量生成的 golden page 锚点 |

> 顺序原则：**内容先行 → 视觉后置 → 单页样张 → 批量生成**。
> 文案未确认不解析模板；样张未确认不批量生成。

## 6. 模板适配器（核心子系统）

### 6.1 三条生成路径与判定

| 路径 | 适用 | 实现 |
|---|---|---|
| **A. 版式复用** | 模板版式干净、有正文占位符（企业式模板） | `add_slide(layout)` + 填占位符 |
| **B. 样张克隆**（主力） | 装饰在页面上、版式是空壳（**西财两套即此类**） | 克隆样张 XML → 清空/替换文本 → 保留装饰 |
| **C. 风格合成** | 模板缺该角色（如"技术路线图""实验结果""对比表"） | 提取视觉 token（标题区几何/logo 位/色/字体/边距）在空白页上合成 |

**判定规则（自动）**：统计样张的 `占位符数 / 浮动文本框数 / 图片装饰占比`
- 占位符 ≥2 且文本框少 → A
- 占位符少、文本框多、有装饰图 → **B**
- 无匹配角色 → C

### 6.2 样张克隆实现要点（实测踩坑）

1. `deepcopy` 源 slide 的 `spTree` 子元素 + `p:bg` 到新页；
2. 关系重映射：`new_part.relate_to(rel.target_part, rel.reltype)`，处理 `r:embed` / `r:id`（图片、超链接）；
3. **文本替换必须按"文本框"整体替换**：保留第一个 run 的 `rPr`，合并全部文本写入首 run，删除其余 run——按 run 逐个替换会重叠乱码（实测标题糊成一团）；
4. **含图表的样张不能直接克隆**：会共享同一 chart part，改一页另一页同变 → 克隆后重建 chart part；
5. 克隆**不继承** notes / 动画 / 批注 → 备注单独写；
6. **不依赖 autofit**：python-pptx 不计算缩排 → 按骨架登记的"容量字数"自己控制文案长度，超了就拆页；
7. 生成后只渲染**改动页**（`--pages`），读 `missingFonts`，避免全量重渲染。

### 6.3 角色分类与骨架登记

给每个样张自动打角色标签（规则 + 首屏文本特征）：

| 角色 | 判据（两套西财模板实测可判别） |
|---|---|
| 封面 | 含校名/校徽 + 大标题 + "汇报人/日期" |
| 目录 | 含"目录 / Contents" + 4–6 个章节条目 |
| 章节过渡 | 含"第X部分 / 0X" + 大号数字 + 背景图，文本极少 |
| 正文·图文 | 标题栏 + 图片 + 多列小标题 |
| 正文·纯文字 | 标题栏 + 多段落（无图或仅装饰图） |
| 正文·多列卡片 | 3–4 个并列卡片（小标题 + 正文） |
| 结尾 | 含"谢谢 / 敬请批评指正" + 汇报人/日期 |
| 其他/模板专属 | 无法归类，登记但默认不使用 |

每个角色登记一份**骨架**：文本框 name + 坐标 + 字号 + run 结构 + 装饰 shape 名单 + **容量字数**（按原样张文本长度推算，如"小标题 ≤10 字 / 正文 ≤80 字"）。

### 6.4 缺口与降级

答辩需要的角色，模板往往没有：**图表页、技术路线/流程图、对比表、时间线、数据大字报、Q&A 备份页**。

降级策略（按优先级）：
1. 用样板式样张改造（如"多列卡片"→ 对比页）；
2. 用 Path C 合成：复用标题栏 + logo + 配色 + 边距，正文区放原生图表/表格，**不新增装饰**；
3. 实在没有：改用"纯文字列点 + 一图"的最简表达，并告知用户"你的模板没有图表版式，我用最小改动合成"。

### 6.5 污染清洗 / 体积 / 字体

| 项目 | 处理 |
|---|---|
| 残留占位符与示例文字 | 自动检出 `<单击此处添加标题>`、"添加标题描述"、"XXX"、"20XX年"、模板说明文字 |
| 模板示例页 | 默认不保留（只保留被选中的样张）；如需保留，标为"附录/备份" |
| 未使用母版/版式 | 清理（典雅红 24→实际用 4；西财蓝 10→3） |
| 装饰大图 | 降采样 ≤1920px + JPEG q80；无透明转 JPEG；去重；**目标成品 <15MB** |
| 字体 | 建"替换表"：思源宋体 CN → 宋体/Noto Serif SC；微软雅黑 → 微软雅黑（Windows）/ PingFang SC（Mac）；写 `a:ea`+`a:cs`；对用户显式提示"你的电脑可能没有 X 字体" |
| 动画/切换 | 默认清空（答辩现场易翻车） |

## 7. 内容引擎

### 7.1 场景规范表（含官方依据）

| 场景 | 时长 | 页数 | 必备章节 | 高频扣分 |
|---|---|---|---|---|
| 课程/组会汇报 | 8–12 min | 10–15 | 背景—问题—文献—方法—结果—讨论—结论—下一步 | 抄摘要；整页文字；只罗列不评价；超时 |
| 开题答辩 | 8+7 min 起 | 12–18 | 立题依据—综述—科学问题—研究内容—技术路线—前期基础—可行性—进度—预期成果 | 问题边界不清；路线只有方框；进度空泛；文献陈旧 |
| 中期检查 | ~10 min | 10–15 | 已完成—阶段成果—存在问题—解决途径—下一步 | 报喜不报忧；问题与对策不对应；无量化进度 |
| 本科答辩 | 10+5 min（个别 ≤12 页） | 10–15 | 背景—方法—结果—结论—不足—致谢 | 超页；念稿；图表无标注；致谢漏导师 |
| 学术硕士 | ≥20 min + 10–15 提问 | 20–25 | 背景—综述—问题—方法—结果—讨论—结论—创新—不足—展望—致谢 | 创新点说不清；数字与论文不符；未回应盲评意见 |
| 专业硕士 | ~20 min | 18–25 | 行业背景—问题—方案—实施/案例—效果验证—效益—不足—致谢 | 写成学术论文；无应用数据；案例空泛 |
| 博士 | ≥40 min + 提问 | 30–40 | 背景—综述—模型/假设—方法—实验—结果—讨论—创新—局限—展望—成果—致谢 | 创新点堆砌；章节断层；回避局限 |

> 换算规则：**页数 ≈ 时长(分钟) × 1～1.2**；总时长 ≤ 目标 × 90%；backup 页 ≥ 5。
> 官方硬性规定多为"陈述不少于 X 分钟"、个别"≤12 页"，因此 skill 用**可配置区间**而非死数字。

### 7.2 压缩规则（论文 → 答辩）

| 论文部分 | 答辩处理 | 压缩比 |
|---|---|---|
| 摘要 | 拆成"研究问题 + 核心结论" | 高 |
| 绪论/综述 | 1–2 页，只留 gap 与"别人差在哪" | 极高 |
| 方法 | 2–3 页，保留路线图/核心公式/实验设计 | 低 |
| 结果 | 3–5 页，每页 1 个核心结果 + 1 张主图 | 低 |
| 讨论 | 1–2 页，贡献 + 与已有工作对比 | 中 |
| 结论/创新点 | 1 页，≤3 条，与结果一一对应 | 高 |
| 不足与展望 | 1 页，2–3 条，真诚具体 | 中 |
| 致谢 | 1 页 | — |

### 7.3 断言式页面

每页 = **一个结论句标题 + 一个证据单元**：
- 标题 ≤20 字、动词开头、含结论（"改进 X 使 F1 提升 4.2%"），不写"实验结果"；
- 证据：图 / 表 / 数据 / 引用，**只放一个**；
- 正文 ≤6 行、每行 ≤20 字；超了拆页，不缩字号；
- 放"讲给别人听的话"，不放论文原文。

### 7.4 讲稿与 Q&A

- 讲稿：每页 1–3 句提词（非逐字稿）+ 过渡句 + 每页时长，合计 ≤ 目标 × 90%；
- Q&A 预案：20–30 问，覆盖概念/为什么做/创新点（≤3）/方法与参数/数据来源/对比/局限/应用；每题 30 秒答案 + 对应备份页编号；
- 备份页：原始数据、参数表、补充实验、伦理批件等，答辩现场直接跳转；
- 做"数字口径表"：保证论文/PPT/口头三处数字一致。

### 7.5 学术诚信红线（依据）

1. **不生成/篡改实验数据图**（补点、平滑、裁剪都不行）——《学术不端行为处理办法》"伪造/篡改"；
2. **不代写核心结论**——AI 可做提纲、润色、排版；《学位法》第 37 条：代写、剽窃、伪造可不授予或撤销学位；
3. **示意图须标注并人工核验**，按《AIGC 使用边界指南 2.0》披露；对外发布按《AI 生成合成内容标识办法》（2025-09-01 施行）标识；
4. **涉密/未公开/患者数据不上传公有云**；医学研究另守《伦理审查办法》；
5. **文献逐条查证**，不虚构引用；访谈问卷须知情同意与匿名化。

### 7.6 学科差异

| 学科 | 核心证据 | 必备页 | 视觉 |
|---|---|---|---|
| 理工 | 实验/仿真/算法对比 | 技术路线、实验设置、误差/消融、复现说明 | 图 > 字，坐标轴单位、误差棒、baseline 表 |
| 财经/经管（本模板主场景） | 数据、模型、案例、政策文本 | 研究设计、数据来源与样本、模型设定、稳健性检验、案例 | 三线表、趋势图、模型示意图；忌满屏文字 |
| 人文社科 | 文本/田野/访谈/问卷 | 理论框架、资料与方法、材料呈现、解释 | 引文页、框架图、编码表 |

| 艺术设计 | 作品与过程 | 概念、过程稿、成品、展陈 | 大图、细节特写 |

## 8. 质量门禁

### 8.1 硬规则（写进 SKILL.md）

1. 忠于模板：不改母版、不换主题色、不引入模板外字体、不加模板没有的装饰；
2. 页面来源可追溯：每页必须来自"某样张克隆"或"声明为合成"，禁止不明来源的自由排版；
3. 每页一个结论：标题必须是结论句；
4. 信息预算：正文 ≥18pt、标题 ≥28pt、图注 ≥12pt；一页正文 ≤6 行；超了拆页不缩字；
5. **不复制模板样张的信息密度**（12pt / 300 字是排版示意，不是可交付状态）；
6. 图表优先，图必有图注 + 数据来源；
7. 无残留：占位符、示例文字、"XXX"、"20XX年" 全清；
8. 无花哨：默认无动画/切换/渐变/阴影/emoji；
9. 时长守恒：≤ 目标 × 90%，页数与时长相配；
10. 学术诚信：见 7.5；
11. 交付体检：体积 <15MB、无缺失字体、无溢出、可正常打开。

### 8.2 校验器

| 脚本 | 检查 |
|---|---|
| `validate_deck.py` | 残留占位符/示例文字、字号下限、单页字数、页数、备注与页面错位、图表来源、字体清单、体积 |
| `render_check.py` | 封装 LOKit：只渲染改动页，返回 `missingFonts`，输出 PNG + 拼图 |
| `montage.py` | 6–12 页拼图，快速目检 |
| 大纲校验 | 生成前拦截：页数×时长、每页有无结论标题与证据 |

原则：**先量后改**——溢出多少 px、字号多少 pt、字数多少，再决定怎么改，不凭感觉大改。

## 附：设计取舍备忘

- **为什么不"套版式"**：实测两模板的版式是空壳，`add_slide` 出白页；装饰全在页面上，只能克隆。
- **为什么读"实际用色"而不是 theme**：典雅红 theme 仍是 Office 蓝，真红色硬编码在形状里。
- **为什么坚持信息预算**：模板样张 12pt/300 字是排版示意，直接沿用 = 答辩事故。
- **为什么把体积和字体放进 P0**：243MB 传不出去、缺字体静默回退，都会让"看起来很完美"的 deck 在交付环节失败。
- **为什么把校验做成脚本**：参考 skill 最大的启示不是模板多漂亮，而是把经验固化成可执行检查项。

4. theme 色 ≠ 品牌色，必须统计页面实际用色；
5. 渲染质检能抓到结构校验抓不到的换行/溢出问题。
