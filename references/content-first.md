# 逐页文案稿（Content-First）

> 这是工作流的**第一道确认门**。目的只有一个：**在碰模板之前，确认每页讲什么、页与页怎么接。**

## 为什么必须先写文案

中文高校模板几乎都是"三栏 + 配图"的固定骨架。如果先看模板再写内容，会发生两件坏事：

1. **为凑栏数而拼板块**：模板是三栏，就把"数据来源""变量测度""识别策略"这三个本可以各占一页的内容硬塞进一页；
2. **内容被版式切碎**：一个完整论点被拆到两页，讲的时候接不上。

**正确顺序是：内容 → 版式。** 先确定"这一页要讲完哪一件事"，再去找能装下它的版式；装不下就拆页或合成版式，**不改内容去迁就版式**。

## 每页格式

```markdown
## P4 · 研究背景
- 页面目的：用两个反常事实引出研究问题
- 标题（结论句）：研究背景：两个待解释的特征事实
- 正文：
  - 特征事实一：2019 年中国 OFDI 存量约八成流向发展中经济体
  - 特征事实二：企业常与国内供应链伙伴协同进入同一东道国
  - 研究问题：融资约束如何塑造区位选择？供应链网络能否缓解？
- 证据：2019 年度中国对外直接投资统计公报（八成 / 两成）
- 备注：讲稿 1–3 句，写"讲给别人听的话"，不是论文原文
- 时长：100s
```

要点：
- **标题写结论句**，不写名词标签（"研究背景"→"研究背景：两个待解释的特征事实"）；
- **正文条目 ≤6 条**，每条是一句可讲的话；
- **证据只写一个**（哪张图/哪张表/哪组数据），不要一页堆三个；
- **备注不是摘要**，是台上要说、但页面不显示的话；
- **不写版式**：不要写"这一页用三栏"、"这一页放左边图右边字"——那是 Step 3 的事。

## 用户确认清单（逐页过）

| # | 确认点 | 不通过的样子 |
|---|---|---|
| 1 | 每页只有一个完整论点 | 一页既讲背景又讲方法 |
| 2 | 页与页构成论证链：背景→问题→假说→设计→结论 | 页序跳来跳去、前页埋的问题后页不接 |
| 3 | **没有为凑模板栏数把不同板块塞一页** | "数据来源+变量测度+识别策略"硬拼成三栏 |
| 4 | 该拆的拆、该并的并 | 一页 300 字；或每页只有一句话 |
| 4.5 | **每页条目数会被完整放进版式**（不因槽位少而合并/删减） | 5 项稳健性只做 4 个；2 个假说硬凑 3 张卡 |
| 5 | 数字/结论与论文一致，没有编造 | 出现论文里没有的数据或结论 |
| 6 | 页数 × 时长配平 | 12 分钟讲 20 页，或 5 分钟讲 3 页 |

## 常见反例（本轮实测踩过）

**反例 1：为三栏硬拼**
> P6 研究设计：数据与样本 / 变量与模型 / 识别策略

三个板块各自都够讲 40 秒，挤在一页 → 每栏只能放一句话，老师问细节时没有支撑。
**正确做法**：拆成两页（数据与变量一页、识别策略一页），或明确"这一页只讲清单，细节在讲稿/backup"。

**反例 2：一页塞两个论点**
> "研究背景 + 研究问题" 放一页

如果研究问题需要单独展开，就应拆页；如果只是承接句，可以放页尾一句。
**判断标准**：这一页的标题能不能同时概括这两块？不能就拆。

**反例 3：标题是名词标签**
> 标题："研究设计"

听众不知道你要讲什么。改成结论句："研究设计：三维面板 + PPIL 估计 + 工具变量"。

## 文案 → 版式的映射（Step 3 用）

文案确认后，统计每页的**结构类型**，再去找样张：

| 文案结构 | 需要的版式角色 |
|---|---|
| 1 个论点 + 3 个并列要点 | 三栏页 / 三列卡片 |
| 1 个论点 + 1 个主证据（图/表） | 图表页 / 表格页 / 图文页 |
| 递进流程（3–5 步） | 流程/时间线页（模板常缺 → 合成） |
| 对比（A vs B） | 对比页（模板常缺 → 合成） |
| 单段论述 | 纯文字页 |

**如果模板没有对应角色**：先合成（Path C），再退一步才是改文案结构，且必须回到 Step 2 和用户确认——**不允许在生成阶段偷偷合并板块**。
