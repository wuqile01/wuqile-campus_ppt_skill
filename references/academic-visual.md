# 学术汇报的视觉与合规规范

> 这个文件解决什么问题：给出"投影看得清 + 图表合规范 + 不碰学术红线"的硬底线，供 Step 3 定视觉方案、Step 4 验样张、Step 6 质检时逐条对照。

## 1. 字号阶梯（投影可读）

| 元素 | 下限 | 推荐 | 说明 |
|---|---|---|---|
| 页标题 | 28pt | 32–36pt | 标题栏最多容 2 行，>20 字必折行 |
| 章节页大字 | 36pt | 44–60pt | 只放大字 + 一行副标题 |
| 正文/条目 | **18pt** | 18–22pt | 报告厅后排可读的底线 |
| 表格正文 | **13pt** | 14–16pt | 行高随字号走，行数 ≤6 |
| 图注 / 表注 / 数据来源 | **12pt** | 12–14pt | 低于 12pt 等于没写 |
| 页码 / 页脚 | 10pt | 10–12pt | 只做辅助，不承载信息 |

**模板风险提示（实测）**：西财两套官方模板样张正文低至 **12pt**，单页最高 305 / 342 字（典雅红 / 西财蓝）。这是"排版示意"，不是可交付状态（硬规则 9）。

处理顺序，不许跳级：
1. **先改文案**（删字、拆页）——最有效；
2. **再改版式**（三栏 → 两栏 / 全宽，回 Step 3 换样张）；
3. **最后才调字号**，且正文不得低于 18pt；
4. **绝不靠缩字号硬塞**。

`validate_deck.py` 会把 <12pt 报 P1、单页字数超预算报 P1/P0；但它查不到"12pt 投影看不清"，这条只能靠人眼 + golden page 基准。

## 2. 中文字体与字重

| 层 | 建议 | 说明 |
|---|---|---|
| 页标题 | 模板自带标题字体，Heavy/Bold | 不换成模板外字体（硬规则 5） |
| 正文 | 1 种，Regular | 全篇字体总数 ≤2（标题 + 正文）+ 数字字体 |
| 数字/英文 | 模板内 Arial / Calibri | 中英混排时行高按中文算 |
| 字重 | 不用 Light / Thin | 投影后细笔画会"糊" |
| 中西文 | 同时写 `a:latin` / `a:ea` / `a:cs` | 只写 latin，中文会回退，字距异常 |

模板若用衬线体（如典雅红的思源宋体 CN Heavy），**全篇保持衬线**；换成黑体会让整份 deck 失去学校风格。

## 3. 图表规范

### 3.1 选图型

| 想表达 | 用什么 | 不要用 |
|---|---|---|
| 趋势 | 折线图（≤4 条线） | 3D 柱、饼图 |
| 构成 | 堆叠柱 / 100% 堆叠 | 超过 4 类的饼图 |
| 组间对比 | 分组柱、点图 | 双 Y 轴（易误读） |
| 相关 | 散点 + 拟合线 | 截断纵轴夸大差异 |
| 分布 | 箱线图、直方图 | 平滑掉方差的"趋势线" |

### 3.2 三线表（学术标准）

- 顶线、底线 1.5pt，表头下细线 0.75pt，**中间和两侧不加竖线**；
- 表头加粗；单位写在表头（"（亿元）"）；全表小数位统一；
- 显著性标记 `*` `**` `***` 必须在表注里写清含义与水平；
- 表格行数 ≤6，行高显式设置（默认行高容易过松）。

### 3.3 图注 / 表注 / 来源（缺一不可，硬规则 10）

| 项 | 写什么 | 例 |
|---|---|---|
| 图注 | 编号 + 一句话说明"看什么" | 图 3 融资约束对 OFDI 扩展边际的影响 |
| 表注 | 编号 + 变量说明 + 显著性含义 | 表 2 变量定义与描述统计 |
| 坐标轴 | 名称 + 单位 | 融资约束指数（0–1） |
| 来源 | 数据/文献出处 | 数据来源：CSMAR，作者计算 |
| 统计 | 误差棒含义、n、显著性 | 误差棒为 ±1 SE；n = 12,480 |

### 3.4 真实数据铁律

图表必须来自真实数据、真实模型输出。AI 只能做**示意图**（流程、框架、概念示意），且必须标注"示意图"，并由作者人工核验。

禁止清单：3D 效果、截断坐标轴起点、平滑补点、静默删异常值、双 Y 轴错位、把文字描述画成"柱状图"。

## 4. 配色克制

**先统计"模板实际用色"，不要读 theme 色**（实测：典雅红 theme 仍是 Office 默认蓝 4874CB，真红色硬编码在形状里）。

统计方法：

```bash
python3 <SKILL_ROOT>/scripts/inspect_template.py "<学校模板.pptx>" -o profile/
# 看 profile/template-profile.md 的「实际用色（来自页面形状，非 theme）」表
```

实测结果：

| 模板 | 实际主色（出现次数） | 结论 |
|---|---|---|
| 典雅红 | `B1221C`（234）、`D08349`、`F6EDCE`、`A00303` | 红为主、金/米为辅 |
| 西财蓝1 | `376FFF`（36）、`637490`（21）、`1271BA`（15） | 亮蓝为主、灰蓝为次 |

这些用色 + 标题区几何 + 字体 + 边距，就是模板的**视觉 token**。走 Path C 合成页时只复用这些 token，不新增装饰。

规则：
- 只用**模板实际出现过**的颜色，禁止引入新色板；
- 强调色 ≤2 个，只用于"结论数字、关键对比项"；
- 图表配色从模板用色里取（实测样例：柱 = `376FFF`，对比柱 = `FFCD69`）；
- 禁止渐变、阴影、发光描边、圆角卡片层层叠加、emoji、装饰性图标堆砌（硬规则 12）。

## 5. 字体替换表（交付必查）

学校模板常用字体在答辩教室的 Windows + Office 上经常**根本没装**，且缺字体是**静默回退**（无弹窗，宋体可能悄悄变成黑体，衬线模板风格全丢）。以 `assets/font-fallbacks.json` 为准：

| 模板字体 | 常见于 | Windows 回退 | macOS 回退 | 风险 |
|---|---|---|---|---|
| 微软雅黑 | 西财蓝正文/标题 | 微软雅黑 | PingFang SC | 字宽略变，可能溢出 1 行 |
| 思源宋体 CN（Heavy/Medium） | 典雅红标题 | 宋体 | Songti SC | 缺字体 → 黑体，衬线风格丢失 |
| 方正小标宋简体 | 公文式模板标题 | 宋体 | Songti SC | 学生机几乎不可能安装 |
| 阿里巴巴普惠体 | 标题/装饰 | 微软雅黑 | PingFang SC | 字重变化 |
| MiSans | 数字/标题 | 微软雅黑 | PingFang SC | 数字宽度变化 |
| 等线 | Office 默认中文 | 等线 | PingFang SC | macOS 普遍缺失 |
| Poppins / Calibri | 英文大标题/数字 | Arial | Arial | 字号观感变 |

操作要求：
1. 生成时把 `a:latin` / `a:ea` / `a:cs` 三处一起写；
2. 渲染质检读返回的 `missingFonts`，用 `--font-fallbacks` 显式映射；
3. 交付说明里写一句"你的电脑若没有 X 字体，标题会回退成 Y"；
4. 目标机器是 Windows 就先在 Windows 上开一遍（多数答辩教室如此）。

## 6. 常见排版事故

| 现象 | 根因 | 修法（先量后改） |
|---|---|---|
| 标题折行、末字掉行 | 标题 >20 字或框宽按示例文字定 | 先减字；再扩 `w`；最后才降字号 |
| 正文压图 | 克隆后未重设文本框位置 | 按 golden page 的边距重设 `x/y/w` |
| 数字孤立换行（"4.2" 与 "%" 分开） | 中英数混排、框宽临界 | 加不换行空格或改短句 |
| 表格跨页 / 行高过松 | 默认行高 + 行数过多 | 行数 ≤6，显式设行高与内边距 |
| 图片变形 | 未保持纵横比 | 等比缩放，或用比例一致的装饰图 |
| 字号不一致 | 依赖继承，各页不同 | 按 golden page 显式写 `sz`，不靠继承 |
| 文本框溢出 | python-pptx 不算 autofit | 按骨架容量字数控文案，超了拆页 |

## 7. 学术诚信红线（单列，逐条对照）

### 7.1 不生成 / 不篡改实验数据与结果图

补点、平滑、裁剪样本、改纵轴起点、挑"好看"的子样本——**全部不行**，都属《高等学校预防与处理学术不端行为办法》（教育部令第 40 号，2016-09-01 施行）第二十七条所列"伪造科研数据、资料"或"篡改研究成果"。

### 7.2 不代写核心结论与创新点

AI 可做：提纲、压缩、润色、翻译、排版。AI 不可做：替你提出核心结论、机制解释、创新点主张。
《中华人民共和国学位法》（2025-01-01 施行）第三十七条规定：学位论文或实践成果存在代写、剽窃、伪造等学术不端行为的，可不授予学位或撤销学位。

### 7.3 示意图要核验并标注；对外发布要标识

- 示意图（流程/框架/概念图）必须由作者**人工核验内容正确**，并在图注写"示意图"；
- 含 AI 生成内容的对外发布物（公开推送、网站、答辩录制上网），按《人工智能生成合成内容标识办法》（2025-09-01 施行）加显式标识；
- 可参考行业自律文件《AIGC 使用边界指南 2.0》的披露做法（非强制法规）。

### 7.4 数据合规

- 涉密、未公开、患者/被试个人数据**不上传公有云**；
- 医学研究另守《涉及人的生命科学和医学研究伦理审查办法》（2023 年施行），页面写伦理批件号；
- 个人信息处理守《中华人民共和国个人信息保护法》（2021-11-01 施行）；访谈录音、原始问卷不进 PPT。

### 7.5 文献与访谈

- 每条引用逐条查证（作者、年份、期刊、页码），**不虚构引用、不凑参考文献**；
- 访谈/问卷须知情同意 + 匿名化（化名、去机构名、去可识别细节）；
- 引用他人图表须注明"转引自"。

## 8. 用户说"把数据做好看"时的标准回应

> 数据本身我不能改——补点、平滑、裁纵轴、挑样本都属于篡改，答辩被查实是"不授予/撤销学位"级别的问题。能做的合规优化有 5 项：① 换更合适的图表类型（同一组数据）；② 用学校模板的品牌色统一配色、放大字号；③ 补齐坐标轴单位、误差棒、样本量、显著性；④ 标题改成结论句，把数字直接说清；⑤ 如果数据不支撑预期，就如实写"不显著 / 与假设相反"并解释原因——这通常比硬凑结论加分。

用户坚持要改数据时：**拒绝**，把风险写进交付说明，并给替代方案（补实验、换指标、缩小结论范围）。

## 9. 视觉自检 6 条（Step 6 用）

- [ ] 正文 ≥18pt、标题 ≥28pt、图注 ≥12pt；
- [ ] 配色全部来自模板实际用色，强调色 ≤2；
- [ ] 每张图/表都有编号、图注/表注、数据来源；
- [ ] 坐标轴有名称和单位，误差棒、n、显著性写清；
- [ ] 无渐变/阴影/emoji/3D，表为三线表；
- [ ] 渲染图里没有折行、压图、孤立换行、图片变形。
