# 7 类学术汇报场景骨架

> **这个文件解决什么问题**：在写下第一行文案之前，回答"这次讲多久、多少页、按什么顺序讲、评委盯什么、哪里最容易扣分"。读完它才能进 Step 2 写逐页文案稿。

## 怎么用

1. 用 Step 1 的 8 问确认**场景 / 时长 / 学校硬性规定 / 学科**；
2. 在下面 7 张场景卡里找到你的场景，把"必备章节顺序"抄成 `copy.md` 的页序骨架；
3. 用"页数分配示例"定页数，再用换算规则复核时长；
4. 文案写完后，用"高频扣分点"自检，用"Q&A 题型"列 backup 页清单。

**骨架来自场景，不来自模板。** 先定场景骨架，再找模板样张；顺序反了就会为了套三栏把章节挤变形。

## 7 类场景总表

| 场景 | 典型时长 | 建议页数 | 一句话核心问题 | `validate_deck.py --scene` |
|---|---|---|---|---|
| 课程 / 组会汇报 | 8–12 min | 10–15 | 我读懂了吗？我自己的判断是什么？ | `course` |
| 开题答辩 | 8+7 min 起 | 12–18 | 这个题值得做吗？做得完吗？ | `proposal` |

| 本科答辩 | 10+5 min | 10–15 | 这件事你自己做完了吗？ | `bachelor` |
| 学术硕士 | ≥20 min | 20–25 | 你的创新点成立吗？ | `master` |
| 专业硕士 | 约 20 min | 18–25 | 方案能落地吗？有效益吗？ | `master` |
| 博士答辩 | ≥40 min | 30–40 | 你的贡献成体系吗？ | `phd` |

## 场景卡

### 1. 课程 / 组会汇报

| 项 | 内容 |
|---|---|
| 典型时长 | 8–12 min（组会 10–15 min，含导师追问） |
| 建议页数 | 10–15 |
| 必备章节顺序 | 背景与问题 → 文献缺口 → 方法/分析框架 → 结果/发现 → 讨论 → 结论 → 下一步 |
| 页数分配示例 | 课程 12 页（12 min）：封面 1｜目录 1｜背景与问题 2｜文献缺口 1｜方法 2｜结果 3｜结论 1｜结尾 1 |
| 评委关注点 | 你有没有真读文献；有没有自己的判断；材料/数据从哪来；下一步做什么 |
| 高频扣分点 | 抄摘要当正文；整页文字；只罗列不评价；超时；"综述"写成作者名单 |

### 2. 开题答辩

| 项 | 内容 |
|---|---|
| 典型时长 | 8+7 min 起（陈述 + 提问；个别学校 ≥30 min 含提问） |
| 建议页数 | 12–18 |
| 必备章节顺序 | 立题依据 → 综述与缺口 → 科学问题 → 研究内容 → 技术路线 → 前期基础 → 可行性 → 进度安排 → 预期成果 |
| 页数分配示例 | 开题 15 页（15 min）：封面 1｜目录 1｜立题依据 2｜综述与缺口 2｜科学问题 1｜研究内容 1｜技术路线 2｜前期基础 1｜可行性 1｜进度 1｜预期成果 1｜结尾 1 |
| 评委关注点 | 问题边界清不清；别人差在哪；技术路线走不走得通；有没有前期基础；时间够不够 |
| 高频扣分点 | 问题边界不清（"研究 XX 的影响"）；技术路线只有方框没有方法；进度空泛；文献陈旧；预期成果写成口号 |

### 3. 中期检查

| 项 | 内容 |
|---|---|
| 典型时长 | 约 10 min |
| 建议页数 | 10–15 |
| 必备章节顺序 | 已完成工作 → 阶段成果 → 存在问题 → 解决途径 → 下一步计划 |
| 页数分配示例 | 中期 12 页（10 min）：封面 1｜目录 1｜进度总览 1｜已完成 3｜阶段成果 2｜存在问题 1｜解决途径 1｜下一步 1｜结尾 1 |
| 评委关注点 | 进度是否匹配开题计划；阶段成果够不够；问题认不认识；下一步可不可执行 |
| 高频扣分点 | 报喜不报忧；问题与对策不对应（问题"数据难获取"，对策"继续努力"）；无依据的"完成 60%"；把开题内容又讲一遍 |

### 4. 本科答辩

| 项 | 内容 |
|---|---|
| 典型时长 | 10+5 min（个别学校硬性"≤12 页"；也有学校 15 min） |
| 建议页数 | 10–15 |
| 必备章节顺序 | 背景与问题 → 文献缺口 → 数据与样本 → 方法 → 结果 → 结论与贡献 → 不足与展望 → 致谢 |
| 页数分配示例 | 本科 14 页（10 min）：封面 1｜目录 1｜背景与问题 2｜文献缺口 1｜数据与样本 1｜方法 2｜结果 3｜结论与贡献 1｜不足与展望 1｜结尾 1 |
| 评委关注点 | 问题说不说得清；方法是不是你自己做的；结果与结论对不对得上；图表会不会读 |
| 高频扣分点 | 超页；念稿；图表无标注/无数据来源；致谢漏导师；综述篇幅超过方法+结果 |

### 5. 学术硕士

| 项 | 内容 |
|---|---|
| 典型时长 | ≥20 min 陈述 + 10–15 min 提问 |
| 建议页数 | 20–25 |
| 必备章节顺序 | 背景 → 综述 → 问题 → 方法 → 结果 → 讨论 → 结论 → 创新点 → 不足与展望 → 成果 → 致谢（含 3–4 张章节过渡页）|
| 页数分配示例 | 学硕 22 页（22 min）：封面 1｜目录 1｜章节过渡 3｜背景 2｜综述 2｜问题 1｜方法 3｜结果 4｜讨论 1｜创新点 1｜不足与展望 1｜成果 1｜结尾 1 |
| 评委关注点 | 创新点是否成立且 ≤3 个；方法细节经不经得起追问；数字与论文是否一致；盲评意见有没有回应 |
| 高频扣分点 | 创新点堆砌（列 6 条，每条一句）；PPT 数字与论文对不上；未回应盲评/外审意见；结果页只放图不讲显著性与量级 |

### 6. 专业硕士

| 项 | 内容 |
|---|---|
| 典型时长 | 约 20 min |
| 建议页数 | 18–25 |
| 必备章节顺序 | 行业/企业背景 → 问题诊断 → 方案设计 → 实施与案例 → 效果验证 → 效益（经济/管理） → 不足 → 致谢 |
| 页数分配示例 | 专硕 20 页（20 min）：封面 1｜目录 1｜章节过渡 1｜行业背景 2｜问题诊断 1｜方案设计 2｜实施与案例 5｜效果验证 3｜效益 1｜不足与展望 1｜贡献 1｜结尾 1 |
| 评委关注点 | 方案能不能落地；有没有真实数据；效益怎么算；与学术论文的差别在哪 |
| 高频扣分点 | 写成学术论文（综述占比过大、没有实施）；无应用数据；案例空泛（"某企业"）；效益只有定性描述；不写自己做了什么 |

### 7. 博士答辩

| 项 | 内容 |
|---|---|
| 典型时长 | ≥40 min 陈述 + 提问（个别 ≥60 min） |
| 建议页数 | 30–40（本 skill 上限，超过即按"大制作"拒绝） |
| 必备章节顺序 | 背景 → 综述 → 模型/假设 → 方法 → 实验 → 结果 → 讨论 → 创新 → 局限 → 展望 → 成果 → 致谢 |
| 页数分配示例 | 博士 35 页（40 min）：封面 1｜目录 1｜章节过渡 5｜背景 3｜综述 4｜问题 1｜模型与假设 3｜方法 4｜结果 6｜讨论 2｜创新 2｜局限与展望 1｜成果 1｜结尾 1 |
| 评委关注点 | 创新是否成体系（不是 3 篇小论文拼接）；章节间有没有断层；局限敢不敢讲；独立贡献在哪 |
| 高频扣分点 | 创新点堆砌/拼接感；回避局限；已发表小论文原样贴；40 min 排 50 页必超时 |

## 换算规则

| 规则 | 算法 | 用法 | 反例 |
|---|---|---|---|
| 页数估算 | 页数 ≈ 时长(min) × 1～1.2 | 10 min → 10–12 页；20 min → 20–24 页 | 12 min 排 20 页 → 每页 36 秒，只能念标题 |
| 单页节奏 | 单页 60–90 秒 | 封面/目录/过渡 10–20 s；正文 60–120 s；结果页 120 s | 每页平均 30 s，观众还没看清就翻页 |
| 总时长守恒 | 计划总时长 ≤ 目标 × 90% | 12 min 目标 → 逐页时长合计 ≤ 648 s | 按 100% 排，现场必超时（翻页、口头补充都要时间） |
| backup 页 | ≥5 页，不计入正片页数 | 原始数据/参数表/补充实验/伦理批件/文献对比 | 只有 1 页 backup，被追问时现场翻论文 |
| 硬性规定优先 | 学校规定 > 本表经验值 | 学校说"≤12 页"就 12 页封顶：细节移 backup、合并过渡页 | 用"经验值"顶撞本校通知 |
| 时长反查 | 逐页备注时长相加 = 总预算 | `copy.md` 每页必写"时长：xx s" | 文案没写时长 → 无法配平，最后靠砍页补救 |

> 时长与页数的线性关系只对正文页成立。封面、目录、章节过渡页按 10–20 秒算，否则时间预算会虚高。

## 跨场景差异：课程汇报 ≠ 毕业答辩

| 维度 | 课程 / 组会汇报 | 学位答辩（本/硕/博） |
|---|---|---|
| 本质问题 | 我学到了什么、我怎么看 | **凭什么信你** |
| 听众 | 任课老师 + 同学，追问少 | 答辩委员会，逐项追问 |
| 证据要求 | 引文 + 自己的判断即可 | 可复现的数据/实验 + 站得住的方法 |
| 结论强度 | "我认为 / 我发现" 可以说 | 必须与论文数据一致，禁用"我觉得" |
| 讲者姿态 | 分享 | 被审查 |
| 页数弹性 | 大（10–15 页可浮动） | 小（学校硬规定卡死） |
| 典型失败 | 抄摘要、没观点 | 创新点不清、数字对不上、答不出参数 |
| 骨架关系 | 答辩骨架 ⊂ 课程骨架（答辩多"识别/验证""创新点""不足"） | 课程骨架不能直接用于答辩 |

## 学科差异

| 学科 | 核心证据 | 必备页 | 视觉表达 | 最容易被漏的页 |
|---|---|---|---|---|
| 财经 / 经管 | 数据、模型、案例、政策文本 | 研究设计、数据来源与样本、模型设定、稳健性检验、案例 | 三线表、趋势图、模型示意图 | 稳健性页、样本筛选流程 |
| 理工 | 实验、仿真、算法对比 | 技术路线、实验设置、误差/消融、复现说明 | 图 > 字，坐标轴带单位、误差棒、baseline 表 | 技术路线图、消融实验 |
| 人文社科 | 文本、田野、访谈、问卷 | 理论框架、资料与方法、材料呈现、解释 | 引文页、框架图、编码表 | 理论框架图、材料编码表 |
| 医学 | 临床数据、伦理 | 研究设计、纳排标准、伦理批件号、统计、不良事件 | CONSORT 流程图、表 1、生存曲线 | CONSORT 流程图、伦理批件号 |
| 艺术设计 | 作品与过程 | 概念、过程稿、成品、展陈 | 大图、细节特写 | 过程稿、作品高清图 |

## 页数超了先砍哪

固定顺序，从上往下砍；标 **—** 的那行永不砍：

| 顺序 | 砍什么 | 移到哪 |
|---|---|---|
| 1 | 综述里的作者罗列 | 删，只留 gap 一句 |
| 2 | 背景的政策罗列 | 删，留一个反常事实 |
| 3 | 讨论的展开 | 压成 1 页 |
| 4 | 方法细节/参数 | 移 backup |
| 5 | 次要结果 | 移 backup，只留主结果 |
| — | **研究问题、方法主图、结论/创新点、致谢** | **永不砍** |

## Q&A 题型清单（用来列 backup 页）

| # | 题型 | 典型问法 | 需要哪页 backup |
|---|---|---|---|
| 1 | 概念 | "你说的 XX 到底指什么？" | 定义/测度表 |
| 2 | 为什么做 | "这个问题为什么重要？" | 背景数据页 |
| 3 | 创新点 | "和已有研究比新在哪？" | 与已有工作的对比表 |
| 4 | 方法与参数 | "为什么用这个模型/参数？" | 参数表、公式页 |
| 5 | 数据来源 | "数据哪来的？可靠吗？" | 数据来源与清洗规则表 |
| 6 | 样本与伦理 | "样本怎么选的？有伦理批件吗？" | 纳排标准、伦理批件号 |
| 7 | 对比已有工作 | "和 XX(2023) 结论冲突怎么解释？" | 文献对比表 |
| 8 | 局限 | "这个结论的边界在哪？" | 局限与处理方式 |
| 9 | 应用 | "结果能用来干什么？" | 应用/政策建议页 |

> 每题准备 30 秒答案：定义一句 + 本文怎么处理一句 + 指向 backup 页一句。问答见 `speaker-and-qa.md`。

## 事实依据（锚点，不是普适标准）

| 锚点 | 规定 | 来源性质 | 本 skill 怎么用 |
|---|---|---|---|
| 川农大 · 数媒本科 | 15 min、≤12 页 | 个别学校硬性规定（公开信息/用户提供） | 12 页封顶，砍内容不砍论点 |
| 国科大 · 本科 | 10 + 5 min | 个别学校规定 | 陈述 10 min → 10–12 页 |
| 青科大 · 研究生 | 硕士 ≥20 min、博士 ≥40 min | 个别学校规定 | 页数下限 20–24 / 30–40 |
| 集美大学 · 专硕 | 约 20 min | 个别学校规定 | 专硕 18–22 页 |
| 皖南医科大学 · 硕士开题 | 8 + 7 min | 个别学校规定 | 开题 10–12 页，提问 7 min 全留给 backup |
| 中科院声学所 · 中期 | 约 10 min | 个别单位规定 | 中期 10–12 页 |
| 北林 · 艺术设计开题 | ≥30 min（含提问） | 个别学校规定 | 按 30 min 排 18–25 页 + 作品图 |

> 引用纪律：**没有来源的数字统一标「经验值」**；不写"教育部规定"来吓人。最终一律以本校研究生院/教务处的通知为准，用户给的规章优先于本表。

## 边界：本 skill 不做什么

- ❌ **大创 / 挑战杯 / "互联网+" / 竞赛路演 / 商业计划书 / 项目申报**：营销属性强、需视觉包装，不属学术汇报 → 请走路演/BP 流程；
- ❌ **页数超过 25–40 页的大制作**（作品集、成果汇编）→ 不做；
- ❌ 需要编造实验数据或结论才能凑够页数 → 拒绝，并说明学术诚信风险。

## 反例

- ❌ **拿本科骨架做开题**：开题评委问"这题做得完吗"，你的页全是"已完成结果" → 缺技术路线与进度页，当场答不上。
- ❌ **中期只报喜**：没有"存在问题"页，评委自己发现数据缺口 → 显得你没意识到风险。
- ❌ **专硕写成学术论文**：综述 6 页、实施 1 页 → 被问"企业到底省了多少钱"答不出。
- ❌ **backup 页塞进正片**：12 min 排 20 页，其中 5 页是备用页 → 正片必然念稿。
- ❌ **按模板页数反推时长**：模板有 17 页样张就做 17 页，不管时长 → 时长与页数双失衡。
