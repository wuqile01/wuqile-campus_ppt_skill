# 交付前自检清单（P0 / P1 / P2）

> 这个文件解决什么问题：把"能不能交付"变成一张可打勾的表——按三道确认门 + 生成后质检组织，每条都说清怎么查、不过怎么办。

## 0. 怎么用

**判定级别**

| 级别 | 含义 | 规则 |
|---|---|---|
| **P0** | 交付底线（污染/溢出/字号/合规/体积/打不开） | 任一条不过 → **不交付**，改完重检 |
| **P1** | 质量项（一致性/密度/标题/图表规范） | 应该过；不过需记录原因并让用户知情 |
| **P2** | 加分项（讲稿/Q&A/页码/backup） | 有时间就做，不做不阻塞 |

**检查方式只有两类**：脚本（可复现、给证据）+ 人眼（只认 110dpi 渲染图，不认代码推理）。
顺序固定：门 1 → 门 2 → 门 3 → 批量生成 → P0 → P1 → 交付。**跳门检查等于没检查。**

## 1. 门 1 · 文案稿（Step 2，此时不看模板）

| # | 检查项 | 怎么查 | 不过怎么办 |
|---|---|---|---|
| 1.1 | 每页只有一个完整论点 | 逐页问：这页标题能同时概括所有条目吗？ | 拆页，回 Step 2 |
| 1.2 | 论证链连贯：事实→问题→假说→设计→结论 | 只读标题，串一遍讲得通吗？ | 调页序或补承接页 |
| 1.3 | 没有"为套模板拼接板块" | 看有没有页面在讲 3 件互不相干的事 | 拆页或改成表格/清单页 |
| 1.4 | 标题是结论句、≤20 字 | 逐页数字数；查有没有"研究背景/结果分析" | 按 `content-distill.md` 第 3 节改写 |
| 1.5 | 正文 ≤6 行、≤120 字、1 个证据 | 数行数、数字数 | 拆页，不缩字号 |
| 1.6 | 数字/结论与论文一致，无编造 | 对照论文表/页码，逐条勾 | 改回论文口径 |
| 1.7 | 页数 × 时长配平（总时长 ≤90%） | 见下方命令 | 增删页或调内容 |
| 1.8 | 删减记录完整（每处删除有去向） | 看 `copy.md` 末尾"删减记录"表 | 补"去向：页/backup/口头" |
| 1.9 | 无实证论文已标"尚待实证" | 查标题括注 + 表注 + 无结果图 | 按诚信条款改 |

```bash
# 页数与总时长核对（TARGET_MIN 换成你的目标时长）
grep -oE "时长：[0-9]+s" copy.md | grep -oE "[0-9]+" \
  | awk -v t=12 '{s+=$1} END {printf "合计 %ds / 上限 %ds\n", s, int(t*60*0.9)}'
```

## 2. 门 2 · 视觉方案（Step 3）

| # | 检查项 | 怎么查 | 不过怎么办 |
|---|---|---|---|
| 2.1 | 版式服从内容：先统计结构标签，再找样张 | 对照 `copy.md` 的"三栏/单证据/递进/对比/表格"标签 | 不许为凑样张改内容结构 |
| 2.2 | 每页都有来源：`克隆样张 N` 或 `合成（Path C）` | 看 `visual-plan.md` 逐页映射表 | 补来源声明 |
| 2.3 | 模板缺口有合成方案 | 查缺哪些角色（图表页/对比页/技术路线/表格页） | 按 Path C 合成，复用标题区+logo+用色 |
| 2.4 | 字号密度基准明确 | 看有没有写"正文 18pt / 表格 13–14pt / 图注 12pt" | 补基准，否则 golden page 无从对齐 |
| 2.5 | 配色来自模板实际用色 | 看 `profile/template-profile.md`「实际用色」表 | 删掉自创颜色 |
| 2.6 | 字体替换方案已定 | 对照 `assets/font-fallbacks.json` | 定 Windows/macOS 回退并写进交付说明 |
| 2.7 | 污染清单已登记 | 看 profile 的「污染清单」 | 生成前清洗对应 shape |

```bash
python3 <SKILL_ROOT>/scripts/inspect_template.py "<学校模板.pptx>" -o profile/
```

## 3. 门 3 · 单页样张（Step 4）

| # | 检查项 | 怎么查 | 不过怎么办 |
|---|---|---|---|
| 3.1 | 选的是最危险的那页（非封面/目录） | 看是不是图表页或条目最多的正文页 | 换页重做 |
| 3.2 | 观感像学校模板，不像 AI 拼的 | 人眼看渲染图 | 换样张或补视觉 token |
| 3.3 | 可读性：投影后正文看得清 | 按 18pt 下限核对；<18pt 必须提示风险 | 回门 2 改版式 |
| 3.4 | 无折行、压图、孤立换行 | 渲染图 100% 缩放逐处看 | 先减字→再扩框→最后才调字号 |
| 3.5 | 语气对：标题结论句、备注人话 | 读标题与备注 | 重写 |
| 3.6 | 图片处理正确（装饰图保留/真实图清晰） | 看图片有无变形 | 等比缩放 |
| 3.7 | **确认后写 golden page 基准** | 查 `visual-baseline.md` 是否记录字号/密度/边距/句式 | 没记录 → 批量必散 |

```bash
python3 <SKILL_ROOT>/scripts/build_deck.py "<模板.pptx>" build-plan.json -o out/样张.pptx --only 4
node <LOKIT_CLI> render --input out/样张.pptx --output-dir out/样张-render --dpi 110
```

> `--only` 选信息密度最高的页；`--output-dir` 必须是一个**不存在**的目录。

## 4. 生成后 P0（必须全过）

| # | 检查项 | 怎么查 | 不过怎么办 |
|---|---|---|---|
| 4.1 | 无残留占位符/示例文字 | `validate_deck.py` 的 P0 pollution 列表为空 | 逐个清（"添加标题""XXX""20XX 年"） |
| 4.2 | 无溢出、无文本重叠 | 逐页看渲染图（重点：标题、表格、脚注） | 减字优先，再扩框 |
| 4.3 | 字号达标：正文 ≥18、标题 ≥28、图注 ≥12 | 看 P1 是否报 <12pt；再人眼核 18pt | 回门 2 改版式，不许硬缩 |
| 4.4 | 封面信息完整 | 题目/姓名/学号/导师/学院/日期/校徽逐项 | 补信息 |
| 4.5 | 图表有编号 + 图注 + 数据来源 | 逐图逐表看底部 | 补来源，缺来源的图不放 |
| 4.6 | 页数在场景预算内 | `validate_deck.py` 的 P0 页数告警 | 增删页（演示切片告警也须在交付版消除） |
| 4.7 | 无缺失字体 | `missingFonts` + `qa-report.json` 的 `unknownFonts` | 按 `font-fallbacks.json` 映射并告知用户 |
| 4.8 | 体积 <15MB | `qa-report.json` 的 `sizeMB` | 跑 `optimize_pptx.py` |
| 4.9 | 能正常打开 | 生成机 + 目标机（Office）各开一次，无"修复"提示 | 排查克隆页结构 |
| 4.10 | 页面来源可追溯 | 每页在 `visual-plan.md` 有"克隆 N / 合成" | 补声明 |
| 4.11 | 学术诚信复核 | 无编造数据图、无代写结论、示意图已标注 | 删/改，不解释 |

```bash
python3 <SKILL_ROOT>/scripts/validate_deck.py out/答辩.pptx --scene bachelor --out out/qa-report.json
python3 <SKILL_ROOT>/scripts/optimize_pptx.py out/答辩.pptx -o out/答辩-压缩.pptx --max-width 1920 --quality 82
node <LOKIT_CLI> render --input out/答辩-压缩.pptx --output-dir out/render --dpi 110 --max-input-bytes 400000000
```

> 体积治理实测：73.7MB → 2.8MB（省 96%）；模板 >64MiB 时渲染必须加 `--max-input-bytes`，否则报输入过大。

## 7. 本 skill 实测踩过的坑

| # | 现象 | 根因 | 处理 |
|---|---|---|---|
| 1 | 克隆后背景/校徽/照片空白 | 只 deepcopy 了 spTree，没重映射 `r:embed` 关系 | 克隆后遍历 `r:id` 做 `relate_to`；每页生成后必渲染该页 |
| 2 | 标题糊成一团、两行字重叠 | 按 run 逐个替换，旧 run 没删 | 整框替换：保留首个 run 的 `rPr`，合并文本写入，删其余 run |
| 3 | "答辩人：张明"被挤成两行 | 模板文本框宽度按示例文字定 | 几何覆盖加宽 `w`（实测修过一处）；减字优先 |
| 4 | 表格撑满页面、行高过松 | 默认行高由字号+内边距推 | 显式设 `row.height` 与单元格内边距；行数 ≤6 |
| 5 | 校验报"字号继承"，但渲染是 12pt | 字号来自版式/主题 `lstStyle`，XML 里没有 `sz` | 按 golden page 显式写 `sz`，不依赖继承 |
| 6 | 衬线模板渲染成黑体，无任何报错 | 字体缺失静默回退（思源宋体 → PingFang SC） | 读 `missingFonts`；用 `font-fallbacks.json` 映射；目标机复开 |
| 7 | 渲染报输入过大 | 默认输入上限 64MiB，模板 243MB/约 100MB | `--max-input-bytes 400000000`；`--output-dir` 必须不存在 |
| 8 | 模板 243MB，传输/上传失败 | 单图最大 42MB、30 张图共 231MB | `optimize_pptx.py` 降采样 ≤1920px、q82；目标 <15MB |
| 9 | 页数告警但内容已够 | 演示切片 8 页 < 场景预算 10–15 | 交付版补 backup 或正片页，把 P0 消掉 |

## 8. 交付前最后 5 分钟

```bash
# 1) 终检（P0 全绿再往下）
python3 <SKILL_ROOT>/scripts/validate_deck.py out/答辩-压缩.pptx --scene bachelor
# 2) 体积与页数
ls -lh out/答辩-压缩.pptx
# 3) 字体清单
python3 -c "import json;r=json.load(open('out/qa-report.json'));print('未知字体:',r['unknownFonts'],'| 体积:',r['sizeMB'],'MB')"
# 4) 渲染终版（只渲染改动页，改动用 --pages "3,5"）
node <LOKIT_CLI> render --input out/答辩-压缩.pptx --output-dir out/render-final --dpi 110
```

交付物清单：`答辩.pptx`（+ `答辩-压缩.pptx`）+ `讲稿.md` + `答辩QA预案.md` + `质检报告.md` + PDF 备份。
最后一句话必须对用户说：**在你的答辩电脑上打开一遍，确认字体与替换效果。**

## 附：中文折行丢字（2026-11 实测）

渲染图里若发现"每个折行首字消失"，检查 `a:pPr` 的 `hangingPunct="1"` 与 `algn="just"`。
`build_deck.py` 已自动规范化；若手工编辑页面后复现，按同样方式处理。结构校验查不出这个问题，只能靠渲染目检。

## 附：槽位守恒检查（2026-11 新增）

```bash
python3 <SKILL_ROOT>/scripts/check_plan.py copy.md build-plan.json
```

逐页比对 `copy.md` 条目与幻灯片文本：任何一条内容在页面上找不到 → 退出码 1，必须返工。
典型违规：2 个假说做成 3 张卡（凑槽位）、5 类稳健性只做 4 张卡（删内容）。
